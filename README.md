# WhatBytes Frontend Assignment

A modern and responsive e-commerce product listing application built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Live Demo

https://whatbytes-assignment-mocha.vercel.app

---

## ✨ Features

- Product listing page
- Search functionality
- Category filtering
- Price filtering
- Shopping cart functionality
- Cart item counter
- Responsive design
- Product detail page
- URL-based filters using search params
- Clean and modern UI

---

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Context API
- Lucide Icons
